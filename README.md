# Kapture Finance Collections Voicebot

## Project
Maya is an outbound AI voice agent for Kapture Finance collections.

## Features
- Customer verification
- Overdue EMI collections
- Promise-to-pay capture
- Payment link flow
- Edge-case handling
- Compliance guardrails

## Tools
1. verify_customer
2. log_promise_to_pay
3. send_payment_link
